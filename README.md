# ngu-phap

Web sửa ngữ pháp / paraphrase đa ngôn ngữ.

- Chrome AI hoặc Gemini
- Không dịch
- Không OpenAI
- Một lần bấm = một kết quả
- Giữ nguyên ngôn ngữ gốc

## Ngôn ngữ

- Tự nhận diện
- Tiếng Việt
- English
- 日本語
- Français
- 官话

## Tùy chọn

Phong cách: Không đổi / Tự nhiên hơn / Trang trọng hơn

Độ dài: Không đổi / Ngắn hơn / Dài hơn

## Chrome AI

Không cần API key. Nếu chưa chạy được, bật các flags được ghi ngay trong web rồi khởi động lại Chrome.

## Gemini

Cần mạng, API key Google AI Studio, và chọn model Gemini trong web.

## Offline

Web có cache offline cho file tĩnh. Gemini vẫn cần mạng. Chrome AI có thể chạy offline sau khi Chrome tải model xong.
